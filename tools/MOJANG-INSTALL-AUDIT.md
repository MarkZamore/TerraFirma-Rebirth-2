# Источники чистой установки TerraFirma Rebirth 2

Аудит от 6 ноября 2026 года. Проверены опубликованный манифест
`a92d0d4cb05be9137d13fdabc66fbdade0e9c83a`, исходники сборки `300b596`,
код подготовки runtime и официальные метаданные Minecraft 1.21.1.
Платформа сборки — NeoForge 21.1.248 и Java 21.

На стороне пакета нет поля для предварительного заполнения общего кеша
библиотек, Java или установщика. Добавление этих файлов в архив сборки
создало бы дубликаты и сохранило текущие запросы. Перенос сторонней
библиотеки с CDN Mojang требует проверки лицензии и происхождения конкретного
артефакта и поддержки импорта в общий кеш. Лицензия одного проекта не даёт
разрешения перепубликовать весь набор зависимостей или обработанный Minecraft.

Кандидат на устранение лишней загрузки в общем коде — подготовить уже
закреплённую Java 21 до установки NeoForge, передать её официальному
установщику и отключить скачивание Java Mojang только там, где проверен этот
путь. Для приёмки нужен согласованный чистый стенд с пустым кешем и проверкой
целостности, установки NeoForge и запуска. Отдельная миграция существующего
клиентского JAR на официальный CDN затрагивает генератор поставки, stock lock,
подготовку `native-version-metadata.jar` и обновление установленной сборки.
Новые публичные копии оригинального клиента, mappings или ресурсов не нужны.

Аудит проверяет метаданные и код, а не сетевую трассу. Отдельный runtime не
создавался. Запросы модов и служб внутри игры требуют самостоятельного замера.
